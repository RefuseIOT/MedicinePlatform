## 非功能需求追踪

| NFR | 设计手段 | 验证 |
|---|---|---|
| NFR-01 安全 | BCrypt、JWT、角色/归属/状态三层校验 | 越权、token 过期测试 |
| NFR-02 输入安全 | Bean Validation、参数化 SQL、统一异常 | 边界值和非法枚举测试 |
| NFR-03 一致性 | 事务、状态白名单、version 乐观锁 | 双客户端并发操作 |
| NFR-04 性能 | 分页、组合索引、批量查询 | 1000 订单/20 并发 P95 |
| NFR-05 隐私 | 手机号脱敏、日志过滤、文件鉴权 | 代码与日志审查 |
| NFR-06 可用性 | 中文反馈、重试、二次确认 | 页面走查 |
| NFR-07 兼容性 | Chrome/Edge、1366×768 | 浏览器走查 |
| NFR-08 可部署 | Docker Compose、幂等脚本、健康检查 | 空环境启动 |
