## 索引设计说明

1. 主键全部为非聚集语义的业务无关 BIGINT；唯一业务编号使用唯一索引。
2. 列表查询按“归属 ID + 状态 + 时间”建立最左前缀组合索引。
3. `prescription(status,valid_until)` 支撑过期扫描；`flow(prescription_id,created_at)` 支撑时间线。
4. 不为低选择性布尔列单独建索引；分页接口禁止无条件全表扫描。
5. 外键用于表达关系；删除采用业务状态控制，不使用级联删除历史数据。
