# 环境配置

## Java

### jdk 21

下载：https://d10.injdk.cn/openjdk/oraclejdk/21/  中的 jdk-21_windows-x64_bin.exe

### maven 3.9.x

下载：https://maven.apache.org/download.cgi  中的 apache-maven-3.9.16-bin.zip

> maven镜像配置教程 https://maven.aliyun.com/mvn/guide

### Spring boot 3.5.x

会在pom.xml写，版本3.5.16

可以要参考的：[Maven Central: org.springframework.boot:spring-boot-starter-parent:3.5.16](https://central.sonatype.com/artifact/org.springframework.boot/spring-boot-starter-parent/3.5.16)



## Node

### Nodejs 22.x

下载：https://nodejs.org/zh-cn/download 中的 v22.23.4，msi、zip自己按情况选

> 镜像配置：
>
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```



### Vue 3

将会用 npm 管理，lastest即可（3.5.44）
